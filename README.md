# Flashcard-o-matic

This is a **React-based Flashcard Application** built to help students and teachers manage and study flashcards. The application allows teachers to create and edit flashcard decks for various subjects, and students can use these decks to study effectively.

![Flashcard Application](https://github.com/user-attachments/assets/817a922f-dfb8-4375-a0eb-b0266e3182c3)

---

## 🎯 **Learning Objectives**

- Rendering and state management in a single-page application.
- Create and manage React function components.  
- Use React **hooks** like `useState()`, `useParams()`, and `useHistory()` for dynamic state management and routing.  
- Debug React code through console output and the VS Code debugger.  
- Implement routing, including nested routes, using **React Router**.  

---

## 💻 **Technologies Used**

- **Frontend:** React.js, HTML5
- **Routing:** React Router  
- **State Management:** React `useState()` Hook  
- **Styling:** CSS, Bootstrap
- **Testing:** Qualified.io Testing Suite  

---

## 🛠️ **Features**

### 📚 **Deck Management**
- **Create Decks**: Teachers can create new decks for their subjects.  
- **Edit Decks**: Update deck details and manage cards within the deck.  
- **Delete Decks**: Remove a deck permanently from the list.  

### 🃏 **Card Management**
- **Add Cards**: Add flashcards to a specific deck.  
- **Edit Cards**: Update individual flashcards.  
- **Delete Cards**: Remove flashcards from the deck.
